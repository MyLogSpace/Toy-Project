# Luxury Hotel Reservation UI

럭셔리 호텔 브랜드의 분위기를 타이포그래피와 여백, 인터랙션으로 표현한 예약 UI 연습 프로젝트입니다.

## 프로젝트 소개

AI 기능 없이 UI 디자인과 사용자 인터랙션에 집중해 제작한 웹 프로젝트입니다. 럭셔리 호텔 브랜드의 시각적 분위기를 표현하고, 객실을 비교하며 예약 정보를 확인하는 사용자 경험을 설계했습니다.

## 주요 기능

* **호텔 예약 UI:** 예약 시스템과 지도 연동을 시도한 예약 인터페이스
* **객실 비교:** Duplex 스위트 객실 3종을 비교할 수 있는 UI 구성
* **브랜드 스타일링:** Cinzel 세리프 타이포그래피와 여백을 활용한 고급스러운 분위기 연출

## 사용 기술

* HTML
* CSS
* JavaScript

## 학습 및 구현 포인트

* 예약 UI와 지도 연동을 처음으로 구현하며 외부 기능과 화면을 연결하는 경험을 쌓았습니다.
* Cinzel 세리프 타이포그래피와 여백을 활용해 브랜드의 시각적 분위기를 표현했습니다.
* 객실별 특징을 비교할 수 있도록 정보를 구조화하고 UI로 구성했습니다.

## 프로젝트 회고

AI 기능이나 복잡한 시각 효과에 의존하지 않고, 타이포그래피와 여백만으로 브랜드의 무드를 표현하는 방법을 익혔습니다. 기능 구현뿐 아니라 서비스의 성격에 맞는 시각적 경험을 설계하는 것의 중요성을 배웠습니다.
