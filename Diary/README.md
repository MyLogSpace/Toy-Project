# 추억의 일기장 | Retro Diary

2000년대 인터넷 익스플로러 브라우저의 감성을 CSS와 순수 JavaScript로 재현한 인터랙티브 웹 프로젝트입니다.

## 프로젝트 소개

과거 인터넷 브라우저와 개인 홈페이지의 향수를 웹 UI로 표현한 실험 프로젝트입니다. 익숙한 레거시 브라우저 창을 세밀하게 구현하고, 별 파티클과 탭, 모달 인터랙션을 더해 직접 탐색할 수 있는 다이어리 화면을 구성했습니다.

## 주요 기능

* **레트로 브라우저 UI:** 2000년대 인터넷 익스플로러 창을 CSS로 재현
* **별 파티클 인터랙션:** 순수 JavaScript를 활용한 반짝이는 별 효과 구현
* **다이어리 탭:** 다이어리와 방명록을 전환하는 인터페이스 구성
* **모달 인터랙션:** 화면 내 콘텐츠를 모달 형태로 확인할 수 있는 구조 설계

## 사용 기술

* HTML
* CSS
* Vanilla JavaScript

## 학습 및 구현 포인트

* CSS를 세밀하게 조정해 레거시 브라우저 UI의 형태와 디테일을 재현했습니다.
* 별 파티클 효과를 순수 JavaScript로 구현하며 화면 인터랙션을 직접 제어했습니다.
* 탭과 모달을 조합해 여러 콘텐츠를 탐색할 수 있는 UI 구조를 설계했습니다.

## 프로젝트 회고

레거시 브라우저 UI를 세밀하게 재현하며 CSS의 표현 범위와 세부 제어 방법을 익혔습니다. 별도의 라이브러리 없이 CSS와 JavaScript만으로 시각 효과와 인터랙션을 구현하면서, 웹 기술을 활용해 독창적인 사용자 경험을 만드는 과정을 경험했습니다.
